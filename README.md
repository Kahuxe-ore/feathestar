# feathestar

feathestar のポートフォリオ兼ゲーム制作ページ。ブラウザゲーム「ブロックボール」を掲載しています。

## 中身

- `index.html` … サイト全体（HTML／CSS／JavaScript、ロゴ画像も埋め込み済み）。この1ファイルで完結します。

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリを作成する（例：リポジトリ名 `feathestar`、Public）
2. このフォルダの `index.html` と `README.md` をリポジトリにアップロードする
   - Web画面なら「Add file → Upload files」からそのままアップロードできます
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment** の Source を「Deploy from a branch」にし、Branch を `main` / `(root)` にして Save
5. 数分待つと `https://（GitHubユーザー名）.github.io/feathestar/` で公開されます

## 更新のしかた

- サイトを直したら、新しい `index.html` をリポジトリに上書きアップロード（または push）するだけで反映されます
- 変更履歴は GitHub のコミット履歴に残ります
